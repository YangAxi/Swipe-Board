# UI Contract

## Browse

Sell Swipes / Buy Swipes，默认今天与明天。筛选时间取区间重叠，价格出单比较单价上限，
收单筛选比较预算区间重叠。卡片同时展示每次价格与可用数量。

## Post / Detail

用户显式选择用餐方式与交接方式，详情直接联系。游客跳转身份入口。
所有页面明确演示模式，验证标签说明模拟，邮箱不公开。

## Messages / Account

关联源帖，不产生重复对话。条款包含数量、单价、总价、地点与方式。
确认和完成按钮显示当前用户已确认状态。我的帖子仅允许所有者修改。

## Error / Empty

验证失败保留用户输入，存储失败说明未保存，库存不足提示重新协商。
所有弹窗支持关闭和键盘焦点，报告说明仅本地保存，未发送给运营人员。

## External interfaces

首阶段无真实 HTTP API、邮件或支付接口。本合约描述用户界面行为。
